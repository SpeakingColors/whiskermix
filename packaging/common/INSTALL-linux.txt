WhiskerMix for Linux
====================
1. Unzip, open a terminal in this folder and run:  sh install.sh
   It copies the app to ~/.local/opt/whiskermix, the Shimmer plugins (VST3) to ~/.vst3, adds a menu entry,
   and installs the Digiface USB rule (asks for sudo once) so the app can reach the interface without root.
2. Unplug and replug the Digiface USB, then start "WhiskerMix" from your menu.
Needs PipeWire (default on Bazzite, Fedora, Ubuntu 24.04+) and libusb-1.0 (installed on most systems).
Manual: WhiskerMix-manual.pdf. Uninstall: sh uninstall.sh. A Flatpak is planned so no terminal is needed.
