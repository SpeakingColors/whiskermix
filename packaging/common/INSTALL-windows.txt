WhiskerMix for Windows
======================
1. Run WhiskerMix-Setup.exe. Windows may show "unknown publisher": the app is open source and not code signed, choose "More info" then "Run anyway".
2. The installer puts the app in Program Files\Studio 87\WhiskerMix, the Shimmer plugins (VST3) in Common Files\VST3, and adds Start menu entries (app, manual, uninstaller).
3. Start WhiskerMix and choose your audio device in Settings (ASIO recommended).
Note: Windows builds mix audio only. Digiface USB hardware control is Linux only for now.
Uninstall: Start menu, "Uninstall WhiskerMix" (asks whether to keep your workspaces and snapshots).
